SOUND-ONLY WEBSITE UPDATE

This package adds only the optional immersive sound system and scroll-opening transition.
It does not add or redesign the Archive CMS, create-new-scroll controls, or other Version 2.0 features.

Sound behaviour:
- Off by default.
- Starts only after a visitor deliberately enables Archive ambience.
- The visitor's choice is remembered in their browser.
- Includes subtle generated library ambience and contextual sea/storm ambience.
- Adds brief parchment/drawer-style sounds and a scroll-opening transition.
- Respects reduced-motion preferences.
- Uses browser-generated audio, so there are no third-party audio files or licences.

Deployment:
Copy all files in this package into the local GitHub repository folder, replace existing files,
then commit and push through GitHub Desktop.

D.J. O'BRIEN AUTHOR WEBSITE - VERSION 2

This folder is the complete website root.

Included:
- Brihanon's Archives landing page and individual manuscript page
- Decap CMS collection for creating archive entries
- Hero images, image galleries and captions
- Direct MP4/WebM upload field and YouTube/Vimeo link field
- Editable page backgrounds in CMS under Page Scenery
- Eleven NightCafe images installed as optimised WebP files
- Existing books, characters, timeline, reviews, maps and contact content retained

DEPLOYMENT
1. Back up or download the current GitHub repository.
2. Upload the CONTENTS of this folder to the root of the existing repository.
3. Commit to the main branch.
4. Netlify should deploy automatically.
5. After Netlify reports Published, visit /admin and confirm that "Brihanon's Archives" and "Page Scenery" appear.

IMPORTANT
Netlify runs `npm run build`, which regenerates content/site.json from the editable CMS JSON files.
